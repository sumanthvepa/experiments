# Source-Code License Headers

Before creating or modifying a source file, determine its path relative
to the repository root.

In this repository, all code is licensed under the GNU General Public
License, version 3 or any later version. Use the following copyright
header

`prompts/copyleft-template.txt`

for source files. This applies to implementation code, tests, and type
stubs, including `.py`, `.pyi`, `.js`, `.mjs`, `.html`, `.css`,
and `.jinja2` files. Replace the placeholders and render every line as
a comment using the source language's syntax.

When modifying an existing source file that has no license header, add
the GPL header.

## Existing and Third-Party Code

Preserve existing copyright and license notices.

Do not replace or remove an existing license header unless explicitly
requested by the user.

Do not apply first-party headers to vendored, generated, copied, or
third-party code. Preserve its original licensing.

If a file's ownership, origin, or applicable license is unclear, stop
and ask the user before adding or changing its license header.

## Non-Source Files

Do not add source-code license headers to datasets, Markdown documents,
configuration files, generated artifacts, or media unless a separate
instruction requires one.
